How to explore this project

The site is designed to guide the viewer from classification → representative drug → detailed dossier → explanation media.

01

Select a classification

Start by understanding whether the tablet is classified by preparation method, route of administration, or modified-release behavior.

02

Open a representative dossier

Each tablet type includes a representative example so the classification becomes concrete and easier to present.

03

Switch the viewing lens

Compare how the same tablet type is explained to a patient versus how it is analyzed by a pharmacist or student.

04

Replace placeholders with media

Image and video areas are already designed. Later, you can drop in real product photos and recorded explanations.
